# Що приготувати? — фронтенд

Сайт, який отримує дані з API проєкту «Що приготувати?»: показує список рецептів із пошуком за назвою, має реєстрацію, вхід, профіль користувача і вихід.

## Функціональність

| Сторінка | Файл | Хто бачить |
|---|---|---|
| Головна: список рецептів і пошук за назвою | `index.html` | усі |
| Реєстрація | `register.html` | гості |
| Вхід | `login.html` | гості |
| Профіль: ім'я користувача, ім'я, прізвище, пошта, роль (користувач чи адміністратор) | `profile.html` | авторизовані |

### Авторизація

- Після входу `access` і `refresh` токени зберігаються в `localStorage`. Токен `access` додається в заголовок `Authorization: Bearer <access>` кожного запиту до API.
- Якщо сервер відповів `401` (`access` прострочений), сторінка сама отримує новий `access` за `refresh` через `POST /auth/refresh` і повторює запит. Користувачу не потрібно входити знову, поки діє `refresh`.
- Неавторизований користувач, який відкрив `profile.html`, потрапляє на сторінку входу. Після успішного входу його повертає на сторінку, яку він відкривав.
- Авторизований користувач, який відкрив сторінку входу чи реєстрації, потрапляє на головну.
- У шапці гість бачить кнопки «Увійти» і «Реєстрація». Авторизований користувач бачить своє ім'я (посилання на профіль) і кнопку «Вийти».
- «Вийти» видаляє токени з `localStorage` і відкриває головну сторінку.
- Після успішної реєстрації користувача автоматично авторизовано.

## Як запустити проєкт

1. Запустіть бекенд, він працює на `http://127.0.0.1:8000`.
2. У папці цього проєкту запустіть сервер на порту 3000:

   ```bash
   python3 -m http.server 3000
   ```

3. Відкрийте в браузері `http://localhost:3000`.

Щоб на сторінці були рецепти, їх треба спочатку створити в бекенді.

## Адреси та порти

| Що | Адреса |
|---|---|
| Фронтенд | `http://localhost:3000` |
| Бекенд (API) | `http://127.0.0.1:8000/api/v1` |

Фронтенд відкривайте саме на порту 3000: бекенд дозволяє запити тільки з цієї адреси. Адреса API записана в `API_URL` на початку `auth.js`.
