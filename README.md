# Що приготувати? — фронтенд

Проста сторінка, яка показує список рецептів з API проєкту «Що приготувати?» і дає шукати рецепт за назвою. Написана на HTML, CSS і JavaScript. Потрібна, щоб показати, що фронтенд на іншому порту отримує дані з бекенду.

## Як запустити проєкт

1. Запустіть бекенд, він працює на `http://127.0.0.1:8000`.
2. У папці цього проєкту запустіть сервер на порту 3000:

   ```bash
   python3 -m http.server 3000
   ```

3. Відкрийте в браузері `http://localhost:3000`.

Щоб на сторінці були рецепти, їх треба спочатку створити в бекенді.

## Адреси та порти

| Що | Адреса |
|---|---|
| Фронтенд | `http://localhost:3000` |
| Бекенд (API) | `http://127.0.0.1:8000/api/v1` |

Фронтенд відкривайте саме на порту 3000: бекенд дозволяє запити тільки з цієї адреси. Адреса API записана в `API_URL` на початку `script.js`.
